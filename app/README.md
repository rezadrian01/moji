# MOJI — aplikasi Expo

Aplikasi mobile MOJI (React Native + Expo SDK 58, TypeScript, expo-router).
Spec: `../docs/superpowers/specs/2026-10-31-moji-design.md`. Aturan kerja: `AGENTS.md` dan `../CLAUDE.md`.

```bash
npm install
npx expo start      # dev server (Expo Go / development build)
npm test            # Jest + React Native Testing Library
npm run typecheck   # tsc --noEmit
npm run lint        # expo lint
```
