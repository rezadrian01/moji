Batch berikutnya baru dimulai setelah semua task batch sebelumnya ter-merge.

**Goal:** MVP Android MOJI yang berfungsi penuh. Tujuannya siap dipakai 10–20 responden di rumah selama 1–2 minggu. Isinya: mencatat mood dan konteks, timeline, statistik pribadi, insight mingguan atau on-demand, refleksi, dan jaring pengaman. AI opsional, lewat Cloud Function, Gemini, dan Vertex AI.

**Architecture:**
- Semua data ada di SQLite di HP. Pola dan statistik dihitung deterministik di HP. Gemini hanya menulis kalimat, menyarankan tag, dan menilai risiko.
- Gemini dipanggil lewat satu Cloud Run function (`api`) yang memvalidasi kode undangan di Firestore, membatasi pemakaian, dan tidak pernah menyimpan atau me-log teks.
- Logika domain berupa fungsi murni yang diuji tanpa mock. Layar adalah lapisan tipis di atas repository dan service.

**Tech Stack:**
- **App:** Expo SDK 58, React Native 0.88, TypeScript, expo-router, expo-sqlite, react-native-svg, Reanimated 4, expo-notifications, expo-secure-store. Test: Jest 30 + jest-expo + RNTL v14, sql.js untuk test DB.
- **Backend:** Node.js, `@google-cloud/functions-framework`, `@google-cloud/firestore`, `@google/genai` (mode Vertex), zod. Test: Vitest.

**Spec:** `docs/superpowers/specs/2026-10-31-moji-design.md`

## Global Constraints

- Teks UI dalam Bahasa Indonesia, menyapa dengan "kamu", nada hangat. Tidak menghakimi, tidak menggurui, tanpa positivitas paksa ("Semangat! Pasti bisa!" dilarang). Tanpa istilah diagnosis tentang pengguna (spec §8.4, §7.3).
- Hanya memilih mood yang wajib diisi. Tidak ada validasi yang memarahi (§8.2).
- Tanpa streak, hitungan hari, tanda hari "bolong", atau urgensi palsu. **Tidak ada warna merah** (hue 340°–20°) untuk mood mana pun (§8.3, §8.5).
- Mode terang dan gelap mengikuti sistem (§8.5).
- Animasi menghormati *reduce motion*. Tanpa getar atau haptic dan tanpa konfeti (§8.6).
- Target sentuh ≥ 48dp. Kontras teks ≥ WCAG AA (4.5:1). Font mengikuti skala sistem. Elemen interaktif punya `accessibilityRole` + `accessibilityLabel` (§8.7).
- Penyimpanan catatan tidak pernah menunggu jaringan atau AI. Tindakan hapus selalu dikonfirmasi (§8.8).
- "Butuh bantuan?" ≤ 2 tap dari Beranda (§8.9).
- Teks jurnal tidak pernah dikirim tanpa `aiEnabled && aiConsentAt`. Teks jurnal tidak pernah di-log atau disimpan di server (§7.4).
- Tidak ada rahasia di APK. Satu-satunya konfigurasi klien adalah `EXPO_PUBLIC_API_URL`.
- Mood rendah = mood 1–2. Rentang on-demand 30 hari. Data minimum insight 4 catatan. Timeout AI di klien 15 000 ms (§6.7, §7.2).
- Pakai `npx expo install` untuk dependency app. Cek dokumentasi SDK 58 sebelum memakai API Expo (`app/AGENTS.md`).
- Package Android tetap `com.moji.journal` (spec §3: update tidak boleh menghapus data).
- **Di luar plan ini (P2):** impor data, kunci aplikasi, pola waktu (hari/jam) di statistik.

## Review Focus

1. **Batas hari dan minggu memakai waktu lokal (WIB), bukan UTC.** Contoh: catatan pukul 00:30 Senin WIB masuk minggu yang dimulai Senin itu. → test di Task 2 (`period.ts`) dan Task 20.
2. **Respons AI datang setelah catatan dihapus atau diedit, atau AI dimatikan saat request berjalan.** Harapannya tidak crash, tidak ada `pending_safety` untuk catatan yang sudah tidak ada, dan saran tidak ditempel ke catatan yang hilang. → test di Task 16.
3. **Teks gaul atau ejaan bebas di safety check.** Contoh: huruf berulang ("matiii"), singkatan ("gk kuat lg", "pgn"), tanda baca atau emoji di tengah frasa. Semuanya tetap terdeteksi, dan "mati lampu" tidak memicu. → test di Task 7.
4. **Output Gemini yang menyimpang.** Contoh: tag id yang tidak ditawarkan, `patternTexts` dengan key asing atau kurang, kata klinis seperti "depresi" di teks. Semuanya disaring atau ditolak, lalu aplikasi memakai fallback lokal. → test di Task 11 dan 13.
5. **Edit catatan.** Safety check berjalan ulang. Support sheet tidak muncul lagi untuk catatan yang sama kecuali tingkat risikonya naik. → test di Task 16.
6. **Kode undangan dengan spasi atau huruf kecil.** Contoh: `" moji-r07-k3f9 "` dinormalisasi menjadi `MOJI-R07-K3F9` di klien dan server. → test di Task 9 dan 10.

|---|---|
